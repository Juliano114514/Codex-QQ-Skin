# AI 娘 QQ 秀

右侧「详细信息」栏按摘要、上班状态、个人资料、QQ 秀排列。QQ 秀卡片可以独立收起，不改动工资、打卡和个人资料的数据。

展示框使用 `LLM-show-Latest` 导出资源，标题栏在「还原」旁提供「经典 | 时尚」切换。经典使用 140×226 像素画布；时尚使用 420×678 画布并平滑缩放到同一展示框。完整预设直接显示 Latest 的场景 PNG/GIF，保留经典 64 帧局部动作与时尚动画。系统开启减少动态时回退 PNG，不裁切人物或施加主题滤镜。

QQ 秀在左，设置栏在右，设置项独立垂直滚动。两种风格各有七个角色，分别记住角色和混搭；「还原」只恢复当前风格的当前角色。首项为「角色」；场景及部件选项仅显示所属角色名，如 ChatGPT、DeepSeek、Claude。混搭使用导出的透明 PNG 部件与动态背景，经典的上装前后层、时尚的素体、五官、手势与手指依照各自层级合成。存储键仍为 `codex-qq-skin-qqshow-v1`，兼容原经典角色和部件选择，保留同源窗口同步。

外框、标题、文字、按钮和下拉列表沿用当前皮肤的变量。经典 QQ、七套平台配色及浅深外观保持一致的布局；XP、98、千禧年机箱、皮革手账、Aero、Matrix、拟态主题分别适配展示框材质。原生模式及设置页沿用现有侧栏的隐藏和清理规则。

## 本地导入

在仓库根目录执行：

```powershell
node scripts/qqshow-assets.mjs --import "D:/LLM-show/LLM-show-Latest"
node scripts/injector.mjs --check-payload --theme-dir presets/preset-classic-codex
```

导入器只读取原项目，不修改其资源；校验两种风格各七个角色、PNG/GIF 格式、尺寸与资源路径后，将运行时部件、场景及 Latest 的来源说明整理为 `assets/qqshow.local.json`。只导入当前七套预设所需部件，不复制原生兼容变体、源 SVG 或背景大图。保留原始 PNG/GIF，无需 React、Vite 或新增依赖。重新加载皮肤即可使用；已有注入器可监听资源包变化。原资源更新后再次导入。旧 `assets-classic` 导入格式仍兼容，仅导入旧包时隐藏风格切换。

本地安装器会随 assets 目录复制该文件。没有资源包时只显示导入提示；资源包损坏时记录告警并降级，不阻断已有个人资料与工资功能。
