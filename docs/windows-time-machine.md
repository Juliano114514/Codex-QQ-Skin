# Windows XP 与 Windows 98 独立主题

2026-10-30。两个主题在“美学风格”中独立选择：XP 锁浅色，Win98 锁深色。

- `windows-xp` / `qq-windows-xp`：恢复“Windows XP · 蓝天白云”的原始名称、Luna 窗口、任务窗格、配色和绿丘壁纸，保留已有主题选择兼容性。
- `windows-98` / `qq-windows-98`：“Windows 98 · 经典桌面”，银灰 `#c0c0c0` 面板、深蓝 `#000080` 标题及选中行、白色工作区和输入区、直角与双层立体边缘。
- XP 使用 `appearanceMode: light-only`，Win98 按最终要求使用 `appearanceMode: dark-only`。切换主题时沿用现有外观设置链路同步外观，Win98 的经典灰白外壳保持不变。
- 沿用现有外观设置、导航、输入器和资料数据，不改变布局尺寸、控件点击区域及系统窗口按钮。
- 仅使用项目内 CSS；没有引入第三方库、远程字体或运行时网络资源。
- 按后续反馈去掉全部海绿色背景，工作区使用白色；清除阅读区上下的颜色渐隐层。Win98 控件使用项目已有的 12px Fusion Pixel 字体，正文使用 14px 宋体，代码继续等宽字体。
- 7 天和 30 天趋势沿用经典折线，保留每日悬浮提示，曲线限制在资料卡片的图表内。
- Windows 原生窗口按钮保留原有字形、点击与悬浮行为；按用户最终要求，按钮预留区沿用连续深蓝标题栏，不加独立灰色衬底。
- 撤回上一轮代码语法颜色和文件变更卡片的浅色局部适配，使用原生深色表现。
