# 浮窗布局与性能验证（2026-11-11）

## 修改

- 大气泡、两个小气泡的尺寸和描边统一使用气泡缩放；按大气泡实际尾部与角色头部之间的连线定位小气泡。保留独立角色大小、气泡大小、左右朝向及画布边界。
- 皮肤消息到达后，由有界、合并唤醒的 Dispatcher 回调处理，替代等待下一次一秒轮询。保留周期兜底与宿主退出清理；相邻状态快照仅应用最后一份，提醒和完成事件前先应用已有快照。
- 使用 WPF/C# 搜索文字排版，先以行框筛选自定义内容，再对候选的实际字形检查椭圆包含关系。内置语录保留原有审核布局与评分；全文、提示、字体和颜色保持原有契约。
- 未变化的语录文件按路径、修改时间和大小缓存；保存、恢复默认时失效，保留大小及条数限制。
- 收起、隐藏或查看其他场景时不重复更新额度控件；进入额度场景立即使用最新快照。隐藏时暂停工时控件绘制，后台计时与提醒继续。
- 展开动效从 520 ms 缩为 250 ms，场景交叉淡入淡出从 280 ms 缩为 180 ms，收起从 510 ms 缩为 230 ms；完整可读时间仍为五秒。
- Windows 运行文件清单包含新增 `quote-layout.cs`。

## 测量方法

Windows、Windows PowerShell 5.1、原生 WPF；修改前基线为主仓库 `07b0bf0` / GPT-Niang 子模块 `efd5641`。基线运行文件单独导出，使用隔离数据目录和合成工时、额度，未改写用户工时或账户数据。没有新增或修改自动化测试源码；临时性能测量脚本、原始 JSON 和预览图保存在 Git 忽略的 `output/widget-perf-20261111/`。

- 热点测量：语录选取、额度更新各 40 次；首次文字排版每种内容清空排版缓存测五次，缓存命中测 20 次。以中位数减小首次 JIT 与桌面背景负载的干扰。
- 消息链路：分别运行修改前后真实 `GptSkinPipe`，经标准输入发送 12 条消息，测发送至 UI Dispatcher 回调的往返时间。它不包含最终屏幕呈现。
- 场景循环：隔离的实际 WPF 窗口，使用生产 XAML 与 `Click-Character`，每 650 ms 触发一次，共 48 次，依次循环工时、额度、语录、收起。固定随机种子，语录池含短句及 120 字自定义内容。记录事件处理耗时、进程 CPU、专用内存峰值、Dispatcher 心跳与动画期间 Rendering 回调间隔。

## 热点结果

| 中位耗时 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 语录选取 | 5.14 ms | 1.25 ms |
| 额度控件更新（显示中） | 4.06 ms | 4.05 ms |
| 额度控件更新（气泡收起） | 2.97 ms | 0.17 ms |

自定义长语录的五次平均排版耗时从 3477.17 ms 降为 91.42 ms，约减少 97%。短语录的缓存命中仍在亚毫秒范围。管道回调最大样本由 886.19 ms 降为 16.15 ms，包含修改后首次回调。

## 完整切换循环

以下为最后一组顺序执行的修改前后对照，均为 48 次切换。动画帧间隔仅统计各次实际动效时长，避免把缩短动效后增加的空闲时间混入动画采样。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 点击处理耗时中位数 | 9.34 ms | 8.47 ms |
| 点击处理耗时 P95 | 21.56 ms | 26.52 ms |
| 最长点击处理耗时 | 3581.50 ms | 191.36 ms |
| Dispatcher 心跳最长间隔 | 3626.58 ms | 198.92 ms |
| 进程 CPU 总耗时 | 8375 ms | 4906 ms |
| 进程专用内存峰值 | 299.60 MiB | 297.40 MiB |
| 动画 Rendering 回调间隔 P95 | 19.64 ms | 29.66 ms |

这组 CPU 总耗时降低约 41%，多秒级的首次排版阻塞消除。前两组循环也观察到最长点击耗时由 3.79–3.98 秒降至 157–212 ms，CPU 总耗时降低约 45–53%。普通点击 P95 和动画帧间隔没有显示改善；缩短动效后，动画采样数从 1125 降为 579，因此不能将这些计数当作全局 FPS。仍可能出现约 200 ms 的首次使用抖动，不承诺所有场景无卡顿。内存结果没有显示明显变化，也未做长期泄漏测试。

## 覆盖边界

测量针对本机、指定内容和隔离 WPF 窗口。Rendering 回调不是物理显示器帧率；桌面负载会影响帧间隔，不能据此承诺稳定 60 FPS。CPU 为固定 48 次切换的总进程耗时，专用内存峰值不构成长时间无泄漏证明。未进行 macOS 验证、安装器重建或完整退出重启 Codex。
