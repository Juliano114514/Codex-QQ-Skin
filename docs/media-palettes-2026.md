## 运行时主题规范

颜色在 `assets/theme*.json`；排版、间距、状态规则在 `assets/qq-ui.css`；
六个平台的风格参数与组件映射在 `assets/qq-media.css`。浅色/深色按用户要求使用
`SimSun / 宋体 / Songti SC / serif`。平台字体分别沿官网字体栈配置；
专用 Web 字体只声明字体名，本机未安装时回退到后续本地字体，不宣称已嵌入官网字体。
腾讯的 numFont 只用于官网数字用途，Codex 通用正文不强制使用它。

- 字号：说明 12、控件 13、正文 14、标题 16px；常规 400、标签 600；正文行高 1.6、控件 1.5。
- 间距：4/8/12/16px；普通表单最小高 28px，卡片标题 34px，主题菜单选项 36px。
- 表面：background 为画布/输入槽，panel 为内容卡，panelAlt 为浮层/标题栏；边框统一 line。
- 文本：text 为正文，muted 为说明，accentAlt 为亮色强调文字；品牌 accent 用于填充、选中线与进度。
- 圆角（控件/卡片/主操作）：爱奇艺 8/8/8，抖音 12/12/12，快手 8/8/8，腾讯 8/8/胶囊，优酷 8/10/胶囊，芒果 8/12/22px。
- 浮层阴影统一 0 12px 32px / 黑色 .36；普通卡片无阴影；标题栏只保留低强度品牌色渐变。
- 选中使用品牌色淡底与左侧标记；键盘焦点为 2px 描边；禁用降低透明度；错误文字保留独立红色语义。
- 代码仍用 Cascadia Code / Consolas / SFMono-Regular 等宽栈；不覆盖编辑器与终端的专有字体和语法颜色。

覆盖清单：顶部切换/工具栏、侧栏项目/任务、正文与用户消息、输入框、首页建议卡片、
会话详情卡、成长/个人资料卡与图表、资料编辑弹窗及头像选择、主题菜单、原生菜单/列表/对话框。
当前伙伴区域使用原生详情卡承载；旧 companion 容器若出现也复用卡片规则。
保留窗口拖动/折叠与导航逻辑。官网的大字、透明灰阶按 Codex 密集阅读场景作适配，
不直接复制广告层、播放器尺寸或低对比度文字。
